奶蛙鼠标光标套装 · Windows 可安装版
==========================================

17 个 .cur 对应 Windows 11「设置 → 辅助功能 → 鼠标指针与触控」里的 17 个指针角色。
每个 .cur 内嵌 32 / 48 / 64 / 128 / 256 五档 32bpp 图像，热点按档位等比缩放。
全部 17 个文件已用 Windows LoadImageW 实际加载验证通过。

安装（二选一）
  A. 在「右键安装.inf」上点右键 → 安装 → 到 鼠标属性 → 指针 → 方案 选 NaiwaCursors
  B. 双击「双击安装.bat」，脚本会复制文件到 %LOCALAPPDATA% 并刷新系统光标

恢复默认：鼠标属性 → 指针 → 方案改回「Windows 默认」即可。

文件说明
  *.cur              可安装光标
  cursor_assets/masters/*.png   1024px 透明底设计母版，方便二次修改
  manifest.json      主题规格、17 状态命名与热点表（照参考主题包格式）
  状态映射表.csv     逐状态对照，可直接用 Excel 打开
  总览.png           17 状态视觉总览，红色十字为热点位置

热点口径：箭头/指向类取符号尖端，蓝环/禁止符/准星类取符号中心，
          向上箭头取顶端，定位针取针尖，其余取符号中心。
          改热点只需编辑 manifest.json 或状态映射表.csv 后重新转换。

注意：部分浏览器、游戏和专业软件会自行绘制光标，个别界面不显示系统主题属于软件自身机制。
